Дизайн-система «VL.ru · Места и активности»

Правила для дизайнеров и разработчиков: позиционирование, логотип, цвета, типографика, сетка, компоненты и их состояния, карточки и маркеры карты, токены и требования доступности. Все образцы на этой странице собраны из существующих CSS-классов продукта.

Позиционирование и принципы

Продукт объясняет, где владивостокцу и гостю города провести время: город, природа, море и события на одной карте. Четыре принципа определяют решения в интерфейсе.

Карта как исследование

Главный режим — интерактивная карта: пользователь свободно перемещает и масштабирует её, а фильтры синхронно обновляют точки и список. Справочник — равноправный второй вход для тех, кто ищет текстом и фильтрами. Карта и список используют одни и те же данные.

Полезность прежде декора

Каждый экран отвечает на вопросы: что это, где находится, сколько стоит, когда открыто. Декоративные элементы не конкурируют с данными: никаких украшений поверх фотографий и карты.

Единый VL.ru

Типографика, тон общения и брендовый оранжевый наследуются от VL.ru: продукт читается частью семейства сервисов, а не отдельным приложением. Тёплый, местный, спокойный голос — без рекламных обещаний.

Сценарии без перегрузки

Три сценария — «Город», «Природа», «Море» — плюс события. Интерфейс показывает один сценарий за раз и не смешивает фильтры разных сценариев: пользователь решает одну задачу, не отключая лишнее.

Логотип

До утверждения финального знака используется временная словесная подпись «VL.ru · Места и активности». Словесный знак: оранжевое «VL», тёмное «.ru», через разделительную линию — название продукта.

Правила контраста

  • Основной текст — только --color-text на --color-surface / --color-canvas: контраст около 15:1, выше требований WCAG AA.
  • Ссылки --color-link и вторичный текст --color-text-secondary на светлом фоне — не ниже 4.5:1. Текст уровня caption относится к тому же правилу.
  • Брендовый оранжевый #f97d41 для текста не используется: на белом его контраст около 2.6:1. Оранжевый — фон primary-кнопок, а текст на нём — тёмный --color-on-brand.
  • Цвета категорий (city / nature / sea / event) — для текста бейджей на белом и для маркеров с белой обводкой; soft-варианты — заливка бейджей и подсветки целиком.
  • Информация не кодируется одним цветом: маркеры на карте дублируются иконками, ошибки полей — текстом рядом с полем и атрибутом aria-invalid, успех — подписью.

Типографика

Основной шрифт — Inter Variable (файл подключен локально из assets/fonts, начертания 100–900). Для всех используемых начертаний обязательна поддержка кириллицы. Fallback при недогрузке шрифта: Arial, Helvetica, без засечек.

Плотность и настройки

  • Заголовки: line-height 1.2, межбуквенный трекинг −0.025em, вес 650.
  • Основной текст: line-height 1.5; длинные абзацы (страница места) — 1.7 в колонке не шире --reading-width (46rem).
  • Кегль H1 гибкий: clamp(2rem, 4vw, 2.75rem) — заголовок не ломаёт макет на 320px и не выглядит пустым на широких экранах.
  • Выделение в тексте — весом 600/650, не курсивом и не подчёркиванием. Ссылки — только цветом --color-link плюс подчёркивание при наведении.
  • Числовые и денежные значения пишем как обычный текст с неразрывными пробелами между числом и единицей.

Сетка и размеры

Макет строится на ритме 4/8px: отступы берутся из шкалы --space-1…--space-16 (4–64px), размеры и поля кратны 4px. Базовый контейнер — 1280px, контент читается в колонке до 46rem.

Отступы, контейнер, split-view карты

  • Шкала отступов: 4, 8, 12, 16, 20, 24, 32, 40, 48, 64px. Между карточками сетки — 16px (24px на мобильных внутри панели — 12px).
  • Контейнер страниц: min(100% − 2rem, --container = 80rem / 1280px); на мобильных боковые поля 12px.
  • Карта — split-view: левая панель 24.5rem (392px) + холст карты; на средних экранах панель 20.5–22rem, на широких от 1600px — 26rem.
  • Высота шапки 4.25rem (68px), на мобильных 3.75rem (60px); контент страниц начинается ниже неё.

Мобильные bottom sheets

  • На ширине до 768px диалоги и превью места прижимаются к нижнему краю: скругление только сверху (--radius-xl), полная ширина экрана, учёт env(safe-area-inset-bottom).
  • Превью места — компактная карточка с фото и заголовком; закрывается крестиком или выбором другого маркера; не перекрывает переключатель «Карта / Список».
  • Список мест на мобильном открывается поверх карты по кнопке «Список» и закрывается возвратом на карту — скролл списка не блокирует жесты карты под ним.
  • Закрытие bottom sheet: кнопка «Закрыть», Esc, тап по подложке; свайп вниз — допустимое, но не единственное средство закрытия.

Компоненты

Все состояния показаны статично: рядом лежащие образцы, взаимодействие на этой странице не требуется. Разметка — боевые классы из components.css.

Кнопки

Высота 46px (compact — 40px), min-width подписи не ограничен. Disabled — opacity 0.48 и запрет курсора; aria-disabled допустим для ссылок. Primary — одна на экране, темнота button--dark — для акцентных действий на карточных подложках.

Icon buttons

Размер 44×44px — минимальная мишень. Активное состояние — aria-pressed="true" (мягкий оранжевый фон). У каждой кнопки без видимой подписи — aria-label.

Chips

Default — обводка, active — aria-pressed="true" / is-active с мягкой оранжевой заливкой. chip--filter — крупный вариант для строки фильтров. Список чипов скроллится горизонтально без видимого скроллбара.

Scenario tabs (статичный образец)

Вкладки выбора сценария: группа role="group", активная — aria-pressed="true" (тёмный фон; у «Природа» и «Море» активный цвет соответствует категории). На мобильных растягиваются на три равные колонки.

Поиск

Маркеры и кластер (демо-полотно)

  • Маркер: круг цвета категории с белой обводкой 2px, иконка категории внутри, «хвост»-указатель вниз. Город — по умолчанию (--color-city).
  • Выбранный маркер: брендовый оранжевый --color-brand, тёмная обводка и белое свечение; hover и выбор увеличивают маркер на 15%.
  • Кластер: тёмный круг с числом и подписью «точек», без хвоста; клик приближает карту, пока кластер не раскроется в отдельные маркеры.
  • В прототипе при масштабе менее 135% точки группируются по сценарию и району. При приближении отображаются отдельные маркеры. В production группировку можно заменить геометрической кластеризацией без изменения внешнего вида.
  • Демо-полотно — position: relative; в продукте маркеры абсолютно позиционируются по координатам мира карты.

Маршрут (демо будущего сценария)

Маршруты — на будущее, не входит в текущий сценарий. Стиль линии согласован заранее: штрих 10/8, цвет --color-link, точки-якоря — брендовые круги с белой обводкой.

Изображения и иконки

Фотографии — атмосферные иллюстрации мест, а не каталожные снимки. Пропорция карточки 16:10, галерея страницы места собирается из кадров той же пропорции.

Подложка --color-subtle, пока фото нет

Пока файл не согласован, область фото показывает подложку, лейаут не прыгает.

  • Без наложенного текста, логотипов, рамок и стрелок на фото — подписи живут рядом с изображением.
  • Не используем стоковые «улыбающиеся люди»: реальные локации, погода, свет конкретного времени суток.
  • У каждого изображения — осмысленный alt с атмосферой и названием места; декоративные повторы — с пустым alt.
  • Форматы: jpg/webp, ширина минимум 1200px для карточек; loading="lazy" ниже первого экрана.

Иконки

Сетка 24×24px, обводка 1.8px, скруглённые концы, цвет currentColor (наследует текст). Размеры: 16px (icon--sm), 20px (базовый), 24px (icon--lg). Декоративные иконки — aria-hidden="true"; у кнопок-иконок подпись через aria-label. Набор — локальный, js/icons.js, внешних CDN нет.

Производственная замена карты

Схематичная SVG-карта в прототипе — временная. В продакшене подложка заменяется открытым картографическим API (тайлы OpenStreetMap и библиотека отрисовки). UI-слой — классы и цвета маркеров, кластеры, легенда, токены --color-map-* — не меняется. Подложку подбираем визуально близкой к токенам воды, суши и парков, чтобы маркеры и легенда работали без перекраски.

Accessibility и передача разработчику

Цель — WCAG 2.1 уровня AA. Требования ниже обязательны для всех новых экранов и проверяются перед релизом.

Требования

  • Контраст текста не ниже 4.5:1, крупного текста и значимых графических элементов — 3:1.
  • Интерактивные мишени не меньше 44×44px: кнопки 46px, icon-button 44px, строки чекбоксов и радио 44px.
  • Видимый фокус: :focus-visible, обводка 3px --color-focus, offset 3px; порядок фокуса совпадает с визуальным.
  • Клавиатура: Tab проходит все интерактивные элементы, карта — фокусируемый регион с масштабом клавишами +/−, Esc закрывает диалоги и bottom sheets, диалог держит фокус внутри.
  • prefers-reduced-motion: переходы и анимации отключаются (правило уже есть в base.css, новые анимации добавляем с учётом него).
  • Изображения — с осмысленным alt; декоративные иконки — aria-hidden; состояния — через aria-pressed, aria-expanded, aria-invalid, aria-live для тостов.
  • Масштаб текста 200% не ломает макет: нет фиксированных высот под текст, заголовки на clamp, карточки переносятся.
  • Локальные ресурсы: шрифт и иконки — из assets/, без внешних CDN и трекеров; страница работает офлайн после первой загрузки.

Чек-лист передачи разработчику

  • Все состояния из раздела «Компоненты» покрыты: default, hover, focus-visible, disabled, error, aria-pressed/selected.
  • Цвета, отступы, радиусы, тени и типографика — только из css/tokens.css; хардкод HEX запрещён.
  • Навигация — хэш-маршруты #/map, #/catalog, #/add; активный пункт помечается is-active и aria-current.
  • Шапка и футер единые на всех экранах; skip-link ведёт к основному содержимому.
  • Демонстрационные данные заменяются API; схематичная карта — открытым картографическим API без изменения маркеров и легенды.
  • Маршруты не входят в текущий релиз: стиль согласован (раздел «Карточки и карта»), экраны не верстаем.
  • Перед релизом: прогон чек-листа WCAG AA, тест клавиатурой, 200% текста, включённый prefers-reduced-motion.
