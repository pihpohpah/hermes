## Известные баги карты (исправить в будущем)

Сборка: `mise run map-download` (векторная карта z0–15) и `mise run map-relief`
(рельеф, горизонтали, DEM) — обе воспроизводимы с нуля по скриптам в
`scripts/map/`. Баги ниже проверены на сборке tilemaker v3.2.0
(`scripts/map/Dockerfile.tools`).

1. **«Зубчатая» береговая линия на близких зумах (z14–15).** Полигоны воды
   из `water_polygons.shp` попадают в MVT сильно упрощёнными (тайл z15
   бухты Емар — десятки вершин вместо сотен). Причина — дефолтное
   упрощение геометрии шейпфайла в tilemaker (контрольная сборка с чистыми
   process.lua/config даёт тот же результат). Лечится правкой упрощения
   (config `ocean`: убрать/поднять `simplify_below`, задать `simplify_level`)
   или пост-обработкой геометрии. УЖЕ НЕ ТАК КРИТИЧНО
2. Морская граница от z10 пропадает, остаётся лишь береговая линия, граница по Китаю и Хаб краю пропадает
   (обе карты имею этот баг)
3. **Дальние зумы (до z9–10): граница моря неточная, острова обрезаны.**
   z≤10 рисует `water.pmtiles` (Natural Earth 50 м, без островов) поверх
   которого ложится упрощённая вода region (см. баг 1). Нужна детальная
   вода/берег низких зумов (например, та же water-polygons с низким
   упрощением вместо NE).
4. **«Лесенка» контуров высот на z10–11.9.** Кольца 100 м следуют пиксельной
   сетке DEM (30 м); на z12+ (мелкие кольца 20 м из нативного разрешения)
   всё гладко. Лечится более сильным сглаживанием major-контуров для
   обзорных зумов (`scripts/map/relief/40-chaikin-run.sh`: больше итераций
   Чайкина) или генерацией z10–11 из более детального источника.
5. **Географические подписи неполные.** Пляжи/мысы/острова добавлены в
   process.lua (`natural_label`, острова в landcover), но пороги зумов и
   плотность подписей не настроены — на карте видны не все. Нужна
   донастройка стиля (`web/map/style.json`) и проверка по эталону mapy.
