# Архитектура прототипа

## Принципы

- **Без сборки и фреймворка.** Код читается как есть и переносится в любой стек. Разметку дают чистые функции
  «данные → строка HTML» (`html` из `src/js/core/dom.js`). Тот же контракт легко переписать на компоненты React или Vue.
- **Экраны не знают о данных.** Они вызывают функции из `src/js/api/*`, а те сейчас читают `data/*.json` с искусственной
  задержкой. Подключение backend меняет только `api/`.
- **Состояние экрана живёт в URL.** Поиск, категория и открытая точка лежат в hash. Так любая ссылка воспроизводит вид,
  а кнопка «Назад» работает. Глобальное состояние хранится в `src/js/core/store.js`: выбранный сценарий, пользователь,
  маршрут, отметки «Я приду», свои метки и предложения. Сценарий сохраняется в `localStorage` и переключается в общей шапке.
  Явный `?s=` на карте и в справочнике имеет приоритет и обновляет глобальный выбор; без него используется сохранённый.
  Форма добавления наследует глобальный сценарий только при создании черновика.

## Маршруты

| Hash | Экран | Модуль |
|---|---|---|
| `#/map?s&q&cat&type&place&panel` | Карта | `views/explore.js` + `views/stage.js` |
| `#/now?kind&pin&create` | Быстрые метки | `views/now.js` + `views/stage.js` |
| `#/catalog?s&q&cat&col&type&sort&view` | Справочник | `views/catalog.js` |
| `#/place/:id`, `#/event/:id` | Карточка | `views/detail.js` |
| `#/add?type&fix&scenario&step` | Добавление и правка | `views/add.js` |
| `#/add/success` | Успешная отправка | `views/add.js` |
| `#/profile?tab` | Профиль | `views/profile.js` |
| `#/rules?section` | Правила | `views/rules.js` |
| другое | 404 | `views/not-found.js` |

Hash-роутинг выбран, чтобы прототип работал на любом статическом сервере. Для продакшена с SEO нужен History API
и серверный рендеринг страниц мест (см. [TODO.md](../TODO.md)).

## Контракт экрана

```js
export const someView = {
  title: 'Заголовок вкладки',
  section: 'catalog',             // активный пункт меню или null
  mount(target, ctx) {            // ctx = { path, pattern, params, query }
    // отрисовать в target, подписаться на события
    return {
      update(nextCtx) {},         // смена query без смены экрана
      unmount() {},               // отписки, удаление карт
    };
  },
};
```

Подписки собираются в `createDisposer()` и снимаются в `unmount`. Обработчики делегируются на корень экрана через
`on(root, 'click', '[data-action="…"]', handler)`. Действия размечены атрибутами `data-action`, а не классами.

## Сцена карты

Экраны «Карта» и «Сейчас» — две панели одной постоянной сцены (`views/stage.js`). Сцена создаётся при первом показе
и дальше только скрывается. Поэтому при возврате с карточки места карта остаётся в том же положении и не грузится заново.

- **Ленивое создание карты.** MapLibre создаётся только в видимом контейнере. Если создать её в скрытом, она запомнит
  нулевой размер и будет рисовать растянутую картинку.
- **Прокси.** Панели работают с картой через `stage.map`. Прокси запоминает последние данные, поэтому после пересоздания
  карты (кнопка «Повторить» в ошибке) точки, метки и маршрут восстанавливаются сами.
- **Мобильная раскладка.** Элементы с `data-top-slot` (поиск, чипы) на ширине меньше 48rem физически переносятся
  из шапки панели в плавающую зону над картой. Панель становится шторкой с положениями peek, half и full (`ui/sheet.js`).
- **Отступы карты.** `map.setPadding()` повторяет место, которое занимают панели. Поэтому `flyTo` ставит точку в центр
  свободной области, а маркер выбора места при создании метки совпадает с `getCenter()`.

## Стили

Порядок подключения задан в `src/styles/main.css`: токены, база, компоненты, каркас, экраны. Классы по схеме
`.block__element--modifier`, состояния — через ARIA-атрибуты (`[aria-pressed="true"]`, `[aria-invalid="true"]`,
`[aria-current]`), а не через классы `.is-active`. Так стиль и доступность не расходятся.

Контрольные точки в rem: 30, 48, 64, 80 и 100. При увеличении текста в браузере раскладка переключается вместе с ним.

## Что поменять при переносе в продакшен

1. Собрать CSS и JS бандлером (Vite или esbuild): сейчас `@import` и десятки модулей грузятся по одному.
2. Заменить `src/js/api/*` на реальные запросы. Сигнатуры и формы ответов описаны в [api.md](api.md).
3. Перейти на History API, если нужны индексируемые страницы мест.
4. Выбрать провайдера тайлов и маршрутов с SLA (см. [map.md](map.md)).
5. Убрать отладочный доступ `window.__placesMap` из `views/stage.js`.
