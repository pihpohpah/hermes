# Места — VL.ru

Интерактивный прототип и дизайн-система нового продукта VL.ru: гиперлокальный гид по Владивостоку и Приморью.
В продукте четыре раздела:

- **Карта.** Город, природа и море по отдельности, плюс маршрут между точками.
- **Справочник.** Поиск, подборки и события.
- **«Сейчас».** Быстрые метки жителей вроде «собираемся на футбол через полчаса».
- **Добавление.** Места, события и правки, которые проверяет редакция.
- **«Для вас» и «Мне повезёт».** Рекомендации в профиле и случайное место, событие или маршрут. Логика пока макетная.

Вход по телефону и профиль тоже есть.

Стек — чистые HTML, CSS и JavaScript на ES-модулях, без сборки и зависимостей. Внутри лежит только MapLibre GL JS.
Данные демонстрационные, а сервер имитируется. Контракт API описан в [docs/api.md](docs/api.md).

## Запуск

ES-модули не работают с `file://`, поэтому нужен любой статический сервер:

```bash
cd vlru-places
python3 -m http.server 8080
```

`http.server` не отдаёт заголовков кэширования, поэтому после правок CSS или JS браузер может показывать старую версию.
Обновляйте страницу без кэша: Cmd+Shift+R или Ctrl+Shift+R.

| Страница | Адрес |
|---|---|
| Прототип | http://localhost:8080 |
| Дизайн-система | http://localhost:8080/design-system.html |

Для карты нужен интернет. Тайлы и шрифты подписей грузятся с OpenFreeMap, маршруты строит открытый сервис OSRM.
Без сети прототип показывает состояние «Карта не загрузилась», а справочник продолжает работать.

## Структура

```text
index.html               оболочка приложения
design-system.html       живая дизайн-система: токены, компоненты, правила
src/styles/              tokens.css → base.css → components/ → layout/ → views/ (порядок в main.css)
src/js/main.js           маршруты и переключение экранов
src/js/core/             dom-шаблоны, роутер, состояние, форматирование, гео
src/js/api/              демо-API: места, метки, вход, предложения
src/js/map/              MapLibre: стиль карты, маркеры, кластеры, маршруты
src/js/ui/               компоненты: карточки, окна, шапка, шторка, фильтры
src/js/views/            экраны: карта, «Сейчас», справочник, карточка, форма, профиль
data/                    демо-данные в форме ответов API
assets/                  логотип VL.ru, шрифт Inter, спрайт иконок Lucide, фото
vendor/maplibre-gl/      MapLibre GL JS 6.18 (BSD-3)
docs/                    документация
```
